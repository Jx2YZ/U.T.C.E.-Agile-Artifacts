# Urban Tree Cover Explorer (UTCE) — Agile Project Artifacts

Scrum/Agile process documentation from a **5-person, 3-sprint software project** delivering an interactive urban tree-mapping web application (WordPress-based) for a client, built between April and June 2025.

**My role:** Yunze Jiang — Development Team. Responsibilities included technical exploration and documentation review, sprint burn-down chart ownership and maintenance across all three sprints, 2FA/login investigation, and contribution to sprint development work. Teammates are anonymised by role (Scrum Master, Product Owner, Dev A, QA Engineer) for privacy.

## The product

An interactive map of Melbourne's urban tree cover with:
- Clustered tree markers with detail popups (species, diameter, age, life expectancy, location)
- Parks and Places of Interest layer with category filtering, images, and embedded video
- User-generated markers and ratings
- Full-dataset import and performance tuning within WordPress constraints

- End-to-end Scrum execution: planning → stand-ups → showcase → retrospective, across three sprints
- Requirements management via user stories with acceptance criteria and a groomed, prioritised backlog
- QA discipline: Given/When/Then test cases with recorded pass/fail results per sprint
